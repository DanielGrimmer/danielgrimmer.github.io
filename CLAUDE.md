# CLAUDE.md

**Everything is in [`AGENTS.md`](AGENTS.md).** Read that file first and follow it
unchanged: the operating rules, what the repository is, the checks to run before
pushing, and the encyclopedia rules.

This file exists only because Claude Code loads `CLAUDE.md` automatically and
does not load `AGENTS.md`. It carries no rules of its own, on purpose: two
copies drift, and the ones about pushing to `main` are exactly the ones you do
not want two versions of.
